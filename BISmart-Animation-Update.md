# BISmart AI — Animation Update

This copy keeps the existing BISmart AI routes, backend integration, authentication,
language system, verification tools, matcher, certification wizard, standards explorer,
dashboard, and admin portal intact.

The homepage now has a premium motion layer inspired by the supplied reference video:

- animated hero entrance
- parallax AI glow orbs
- moving BIS / Standards marquee
- scroll-triggered section reveals
- staggered journey cards
- animated feature cards and hover depth
- audience-card hover motion
- FAQ micro-interactions
- responsive mobile behavior
- reduced-motion accessibility support

No new runtime animation dependency was added, so the existing Vite/Tailwind setup remains
compatible with the project.

Run:

    cd bsmart-ai/frontend
    npm install
    npm run dev

Then open the local Vite URL.
